# ELTE IK - CS BSc Final Exam Topics

The student taking the final exam draws a topic at random from the given list of topics. During the oral examination the committee expects the student to know, at a comprehensive level, the most important concepts and results of the given subject, as well as the connections between them.

## Computer Science BSc Final Exam Topics (2018 curriculum)

1. Limits and continuity of functions
2. Differential and integral calculus
3. Numerical methods
4. Number theory, graphs
5. Basics of probability and statistics
6. Artificial intelligence
7. Algorithmic patterns
8. Object oriented modeling
9. Object oriented design
10. Fundamentals of programming languages
11. Object oriented programming languages
12. Formal languages and automata
13. Theory of computation
14. Basic algorithms
15. Data structures and data types
16. Advanced algorithms
17. Operating systems
18. Computer networks
19. Concurrent programming
20. Databases – design and query
21. Databases – optimization and concurrency control
22. Functional programming

## Help improve and extend the topic write-ups!

You can find the gaps and errors on the [Issues](https://github.com/TMD44/elte-ik-pti-bsc-zarovizsga/issues) tab.

Development with **VS Code**:

1. Download and install a [LaTeX distribution](https://www.latex-project.org/get/). E.g.: [MiKTeX](https://miktex.org/download)
2. Clone the repo and open it with VS Code, then install the recommended extensions.
3. When compiling, also install the TeX extensions that pop up. (You may also need [perl](https://www.perl.org/), which can be installed with [choco](https://chocolatey.org/install): `choco install strawberryperl`)
